# Sober Bar & Kitchen — "7am to Midnight"

## Concept
The whole site runs on Gulfport time. The homepage opens on a split day/night hero (the lounge by daylight beside the lit porch with its "WE SAW YOU LOOKING" banner), divided by a brass clock you drag along a 7am→midnight timeline. "Coffee by day. Cocktails after dark." literally changes material at the seam. Scrolling plays out one day on Beach Blvd: 7:00 the Lounge (free, fast WiFi), 12:00 the Bar, 5:30 the porch, 8:00 the Parlor, 11:59 Fri & Sat. The page darkens hour by hour, then breaks into a gig-poster "Every Sunday" Jazz Brunch, the menu, reviews, and the visit block.

## What's in the build
- Static HTML, generated by `_build/*.py` (run `python3 _build/build.py`). It's plain files, so `_build/` can be deleted before deploy.
- All required URLs plus `404.html`. Every page has JSON-LD (35 blocks, all validated): business, menu, FAQ, breadcrumbs, articles, service. Also `llms.txt`, `sitemap.xml`, `robots.txt`, and a Cloudflare Pages `_headers` file with cache rules.
- Self-hosted subset fonts (~95KB total) with metric-matched fallbacks. The CSS is inlined. JS is one file of ~8KB, and the existing GA4 `analytics.js` is kept.
- Images are AVIF/WebP at multiple sizes and lazy-loaded below the fold. The banned Buddha patio photo, the daytime-laptop stills, and the DoorDash watermarks are not used; Ube and Bee's come from Sean's clean stills. Videos are re-encoded to 0.55MB (phone) and 0.79MB (desktop).
- Live open/closed status, today's hours highlighted, and the reserve chooser (any day → 101287, Sunday brunch → 101285, 7+ → call). The phone dock has Call / Reserve / Directions. Cross-page View Transitions and scroll-linked motion are all disabled under `prefers-reduced-motion`.

## Codex MUST fixes (r6)
Screenshots: `_shots/r6/` (index, menu, sunday-jazz-brunch at 390 and 1440, plus home first screens). All four MUSTs and SHOULDs 3–5 are done, each verified with a puppeteer test.

1. **Menu content no longer depends on the IntersectionObserver.** Reveal-on-scroll is now additive: everything renders visible by default, and only elements the observer reports as below the fold get a temporary `.pre` class until they enter view. A 4s safety pass un-hides anything on screen. Results: JS disabled → 0 hidden elements; real scroll test down the mobile menu → 0 elements still hidden in view; all 7 cocktail cards show in `menu-390.png`. The night porch dimming follows the same rule (lit by default, dimmed only when JS confirms it's off-screen).
2. **Mobile drawer is now modal.** The header, main, footer, dock and skip link go `inert` and page scroll locks while it's open. Tab and Shift+Tab cycle inside the drawer (12 Tab presses never left it), Escape closes it, and focus returns to the burger. Following a drawer link releases inert first.
3. **Hero timeline: "Midnight Fri–Sat", with "10pm Sun–Thu" beside it.** On desktop, a 10pm tick reads "10pm Sun–Thu" and the end reads "Midnight Fri–Sat ☾". On phone, the end label is two lines ("12am Fri–Sat / 10pm Sun–Thu"). Labels the knob would overlap hide using a real overlap test against each label's width, and the phone landing position was tuned so the hours label stays visible at rest.
4. **Dark logo on light pages.** A darkened version of the gold logo is used on cream-topped pages (jazz, guides, founder story, press, legal) until the header turns solid; the gold logo stays on dark pages.
- **SHOULD 3:** the menu video band is now 5:1 on desktop and 21:9 on phone (was 3:1 and 1:1). The loop still starts only after the first scroll.
- **SHOULD 4:** the brunch page has "Reserve Sunday brunch" directly under the breadcrumb on phone (hidden on desktop, where the poster button is above the fold).
- **SHOULD 5:** on the brunch page, the header button ("Reserve brunch") and the phone dock's Reserve go straight to productId **101285**, skipping the chooser.

Not done (out of the 10-minute budget): SHOULD 1 (less cream wash on the day image) and SHOULD 2 (simpler mobile day/night treatment).

Lighthouse mobile after these changes: home **94** perf / **100** a11y, menu **94 / 100**, sunday-jazz-brunch **96 / 100**. Earlier runs on the same build varied 94–97. No deploy, no git.
